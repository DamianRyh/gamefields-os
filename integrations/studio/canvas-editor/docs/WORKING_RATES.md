# Ceny sprzedaży i koszty wewnętrzne

Decyzja właściciela23.10.2026: wcześniejsze stawki przeklasyfikowano na wewnętrzne koszty produkcji. Tabele przeniesiono do biblioteki wewnętrznej. Publiczna aplikacja otrzymuje wyłącznie ceny sprzedaży przeliczone na serwerze; źródłowe koszty nie są publikowane w nowych plikach. Dawne rewizje mogą zachowywać wcześniej publiczne dane.
