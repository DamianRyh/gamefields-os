## Contract

`lib/arena-geometry-data.mjs` is generated by `node scripts/build-arena-geometry.mjs` from the **current live Studio sources**, not internal future R02 product cards. It records eight fixed arena IDs, projected top-face area, floor/model-axis bounds, construction bounds excluding floor but including foundations/goals, source file SHA256 values and a combined revision. W1 construction comes from its runtime GLB with the same node transforms as the current loader; its floor is the existing fallback JSON floor. P1 combines construction p1.json with p1-surface.json, matching the renderer.

Both quote-engine and project-dimensions consume the same metadata. Existing quote-engine re-export remains compatible. Areas retain the exact six-decimal values used before this slice; prices and runtime rates do not change. Two-decimal quantity rounding stays in the quote engine. No mesh, material, camera, Project field, schema, import/export migration or SQL is changed.

## Limits and next dependencies

This slice supplies verified live model extents, not approved construction/module specifications. Internal R02 cards contain larger W1/O1/P1 slabs than these live sources. Those revisions need their own asset rollout and approval; they are not silently adopted. Existing source-specific slab/thickness inconsistencies were identified and remain separate work. No thickness claims are derived from nearly planar P1 or zero-thickness W1/O1 source floors.

`tests/project-dimensions.mjs`, included in test:studio, recomputes metadata/source hashes, checks all eight unchanged quote quantities, analytic Octagon area (not either bounding rectangle), custom circle/rectangle, unknown model, Polish formatting and immutable legacy dimensions. Release receipts record actual build/browser/mobile results separately.
