# Gamefields Studio v0.1

Konfigurator boisk: wymiary, nawierzchnie, kolory, linie, wyposażenie i grafiki. Gamefields OS: pulpit, lista i karta projektu.

Podgląd: https://gamefields-studio.ryhfs90.chatgpt.site

Prototyp działa w pamięci sesji; konfiguracje można eksportować i importować jako JSON. Formularz zapytania jest demonstracyjny. Brak bazy danych i rzeczywistego silnika wyceny.
