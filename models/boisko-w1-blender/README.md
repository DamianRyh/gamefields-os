# Panna Ring — GF-CT-001

Źródło: BOISKO W-1 IZOMETRIA 125.pdf, sześć arkuszy W-001–W-006.

Model wizualizacyjny: osiem segmentów koła, 6 RW1 i 2 RW2, dwa zestawy bramkowe BR2. Wysokość paneli 1000 mm, blacha 2 mm, ramy 50×30 mm, żebra 40×30 mm, rury bramek Ø42,4 mm. Otwory bramkowe około 1435×500 mm. Osobne materiały paneli, ramy i bramek; UV paneli przygotowane do grafik.

Przyjęto promień osi 2520 mm i grubość ramy promieniowo 50 mm: obrys zewnętrzny 5090 mm, wewnętrzny 4990 mm, według W-002. Detale RW1/RW2 podają R2500/R2550, czyli promienie o 5 mm większe; wymaga to rozstrzygnięcia przed produkcją. Podział na 45° zapewnia ciągłość całego obwodu zamiast szczelin wynikających z wymiarów pojedynczych prefabrykatów.

Profile ramy mieszczą się między 0 a 1000 mm. Górny obwód jest ciągły, dolny ma wyłącznie otwory bramkowe z projektu. Kontrola zakresu wysokości wszystkich elementów została zapisana w validation.json. Pominięto spoiny, śruby, otwory montażowe i przekroje wewnętrzne rur; plik nie jest dokumentacją produkcyjną.
